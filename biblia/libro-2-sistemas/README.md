LIBRO II

SISTEMAS CONSTRUCTIVOS

INTRODUCCIÓN

En JESUS REY creemos que no existe un único sistema constructivo perfecto.

Cada proyecto posee necesidades diferentes.

Cada terreno presenta desafíos distintos.

Cada cliente tiene objetivos particulares.

Por eso nuestra filosofía consiste en seleccionar la tecnología más adecuada para cada caso.

Este libro reúne los principales sistemas constructivos que forman parte del conocimiento técnico de JESUS REY.

CONTENIDO

01 - Steel Frame

Sistema constructivo industrializado basado en perfiles de acero galvanizado.

02 - Construcción Tradicional

Sistema basado en mampostería, hormigón y técnicas convencionales.

03 - Sistemas Híbridos

Combinación estratégica de múltiples tecnologías constructivas.

04 - Hormigón Celular

Sistema liviano con excelentes propiedades térmicas y energéticas.

05 - Domos

Arquitectura eficiente basada en geometrías geodésicas.

06 - Casas Alpinas

Construcciones inspiradas en estructuras triangulares de alta eficiencia.

07 - Tiny Houses

Viviendas compactas diseñadas para maximizar funcionalidad y eficiencia.

FILOSOFÍA

No defendemos sistemas constructivos.

Defendemos soluciones.

Nuestro objetivo es comprender las necesidades reales de cada proyecto y aplicar la tecnología adecuada para obtener el mejor resultado posible.
